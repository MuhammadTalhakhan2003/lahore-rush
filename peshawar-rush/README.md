# 🛺 Peshawar Rush — Chingchi Edition

The Peshawar sibling of Lahore Rush: the same classic endless 3D runner, rebuilt around the **Peshawar chingchi** (qingqi) — a motorbike front pulling a truck-art tub with a tin canopy, jhalar fringe, a roof-rack carpet and a driver in pakol and patou — through **37 real places of Peshawar**.

*Peshawar Peshawar ae, lala!*

## Run it

```bash
cd peshawar-rush
npm install
npm run dev        # http://localhost:5173
npm run build      # production build in dist/
```

## What's Peshawar about it

- **Hero ride:** the **Chingchi** (default) with its own *Do Pahiya* two-wheel stunt, backflips and nitro; the classic 125 is still in the menu.
- **37 places**, dealt like a shuffled deck: Qissa Khwani Bazaar, Chowk Yadgar, Namak Mandi, Ghanta Ghar, Dabgari, Hashtnagri, Kabuli Gate, Mahabat Khan Masjid, Bala Hisar Fort, Gor Khatri, Sethi Mohalla, Saddar, Peshawar Museum, Islamia College, Khyber Bazaar, Fort Road, Cantt, Edwardes College, Shahi Bagh, Wazir Bagh, Jinnah Park, Tatara Park, Arbab Niaz, Warsak Road, Bara Road, Charsadda Road, Ring Road, Kabul River, Jamrud · Bab-e-Khyber, Hayatabad, University Town, Karkhano, Board Bazaar, Gulbahar and the M-1 Motorway interchange.
- **Landmarks built in code:** Bala Hisar Fort (with the flag), Mahabat Khan Masjid (domes + twin minarets), Islamia College (red-brick tower), Ghanta Ghar clock tower and the giant **Bab-e-Khyber** arch you ride under at Jamrud.
- **Peshawari flavour:** qehwa power-up (instead of lassi), chapli kabab / charsi tikka / kabuli pulao shop signs and posters, **P-E-S-H-A-W-A-R** letters for the daily jackpot, rival **Gul Khan Wheelie**, and dialogue in Peshawari Urdu with a little Pashto (*lala*, *starey mashey*, *dera kha*).
- Everything else (curved-world shader, synthesised engine audio, day/night/rain, Ammi's errands, garage, spin, challenges) is the classic Lahore Rush engine.

Controls are the same as Lahore Rush (← → lane, ↑ jump, Q do-pahiya, ↓ brake, Shift nitro, H horn).
